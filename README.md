# OpenPTV

A third-party open-source PTV (Public Transport Victoria) Android app with no Google Play service dependencies

## Summary

* I have no issues with the PTV app, it's a well-made application, but it does not work on my Google Pixel, as I run GrapheneOS with no Google Play services
* This is an alternative to the PTV application presented in [Material You](https://m3.material.io) style
* OpenPTV is opinionated software. It doesn't try to satisfy everyone's needs. It exists so I can use PTV, but you're welcome to use it and give feedback.
* Open-source with a GPLv3 license
* Calls PTV's official API with a proxy hosted by the project maintainers, or you can provide your own proxy, or make calls directly to PTV's API by providing your own API key
